# Orca Concertante

Orca에서 목표를 한 번 지정하고, 코딩 에이전트들이 역할을 조율하며 검증까지 진행하도록 돕는 범용 스킬입니다. 특정 회사·서비스·프로젝트에 종속되지 않습니다. Orca 공식 제품이 아닌 독립 커뮤니티 프로젝트입니다.

## 설치와 시작

Orca와 등록된 CLI, 설정된 코딩 에이전트가 필요합니다. 선택 도구에는 Python 3.11 이상이 필요합니다.

```bash
npx skills add https://github.com/ComBba/orca-concertante --skill orca-concertante --global
```

설치 후 목표를 자연어로 전달합니다.

> Orca Concertante로 이 앱에 CSV 내보내기를 구현하세요. 기존 동작을 유지하고 독립 검토와 실제 검증까지 진행하세요. 저장소의 PR 규칙을 따르세요.

기본 구성은 Codex가 초기 개념·목표를 정하고, Codex와 Claude가 구현·검토를 나눕니다. Antigravity는 선택적으로 짧은 제3자 의견만 제공합니다. 프로젝트에 맞게 에이전트 조합을 바꿀 수 있습니다.

사용자는 통상적인 다음 작업이나 구현 방법을 반복해서 지정하지 않습니다. 에이전트는 현재 권한 안에서 진행하고, 실제로 필요한 인증·추가 권한·목표 변경만 사용자에게 요청합니다.

## 현재 지원 범위

첫 버전에는 진입 스킬, 협업·인수·복구 지침, 읽기 전용 Orca 상태 조회와 사용량 기반 다음 담당자 제안 도구가 들어 있습니다. 별도 실행기나 상시 데몬은 없습니다.

사용량 제안 도구는 입력된 관측값을 판단합니다. 공급자 지표 자동 수집과 실제 양방향 교대·조정자 인수·재부팅 복구는 아직 실증되지 않았습니다. 설치·테스트 통과를 완전한 무인 실행의 증거로 보고하지 않습니다.

자세한 설치·도구 사용은 [영문 README](README.md), 검증 결과와 미검증 항목은 [validation](docs/validation.md)을 참고하세요.
