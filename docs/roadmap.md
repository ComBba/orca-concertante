# Roadmap

The objective is one-goal coding collaboration with minimal routine user intervention.
Milestones are evidence requirements, not promises of availability.

| Milestone | Acceptance |
|---|---|
| Installable baseline | Portable skill, advisory helpers, independent review, CI and clean installation |
| Live provider observations | Supported read-only adapters distinguish fresh/stale/unavailable without secret export or HUD breakage |
| Real two-way task handoff | Codex→Claude and Claude→Codex on generic tasks, settled ownership, no duplicate edits |
| One-goal completion | Actual implementation, independent review, verification and PR policy without routine “continue” prompts |
| Coordinator continuity | Prove supported Run transfer; otherwise delegate tasks while retaining the proven coordinator |
| Recovery matrix | Interrupted delivery, stale handle, provider limit, daemon/host failure preserve goal and effects |
| Broader platform support | Actual installed Orca integration on Linux and Windows |

Prefer the smallest supported integration over a second scheduler, task database,
daemon, or blanket abstraction. Add a component after a real gap requires it.
