# Generic first goal

Use Orca Concertante to add a CSV export button to this sample task tracker.
Preserve existing behavior. Verify exported headers, escaping, and row counts.
Complete an independent review and follow the repository's PR policy.
Do not change authentication, deployment, or external integrations.

The agent establishes the acceptance criteria and records evidence. The user
does not need to choose the implementer, answer routine implementation questions,
or repeatedly ask it to continue.
